# Decentralized Social Media

## Project Description

Decentralized Social Media is a blockchain-based social networking platform built on Ethereum using Solidity smart contracts. This platform enables users to create profiles, share posts, interact with content through likes, and directly tip content creators with cryptocurrency. Unlike traditional social media platforms, this decentralized approach ensures data ownership, censorship resistance, and direct monetization for creators without intermediaries.

The platform leverages the transparency and immutability of blockchain technology to create a trustless social ecosystem where users have complete control over their data and interactions.

## Project Vision

Our vision is to revolutionize social media by creating a decentralized platform that:

- **Empowers Users**: Give users complete ownership and control over their data and content
- **Enables Direct Monetization**: Allow creators to receive tips and payments directly from their audience without platform fees
- **Ensures Transparency**: Provide a transparent system where all interactions are recorded on the blockchain
- **Promotes Freedom**: Create a censorship-resistant platform where content cannot be arbitrarily removed
- **Builds Community**: Foster genuine connections through cryptocurrency-based incentive mechanisms

## Key Features

### 🔐 **User Profile Management**
- Create unique user profiles with username and bio
- Track user statistics (total posts, likes received, tips earned)
- Decentralized identity without central authority control

### 📝 **Content Creation & Sharing**
- Create and publish posts with content validation
- Immutable post storage on blockchain
- Timestamp verification for all content
- Content length limits to ensure quality

### ❤️ **Social Interactions**
- Like posts to show appreciation
- Prevent self-liking and duplicate likes
- Track social engagement metrics
- Community-driven content curation

### 💰 **Direct Creator Monetization**
- Tip creators directly with cryptocurrency
- Zero platform fees - 100% goes to creators
- Instant, transparent transactions
- Built-in payment system without intermediaries

### 📊 **Analytics & Transparency**
- View comprehensive user statistics
- Track post performance and engagement
- Transparent tip and interaction history
- Real-time data accessible to all users

### 🔍 **Content Discovery**
- Retrieve latest posts from the platform
- View user-specific post histories
- Advanced querying capabilities
- Community-driven content discovery

- **Blockchain**: Ethereum

- **Gas Optimization**: Efficient data structures and function implementations

## Getting Started

1. Deploy the `DecentralizedSocialMedia.sol` contract to Ethereum network
2. Create your user profile using `createProfile()` function
3. Start creating posts with `createPost()` function
4. Interact with other users through `likeAndTipPost()` function
5. Explore content using the various view functions
